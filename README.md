# MirrorCam

Минималистичная студия камеры для чат-рулеток и видеочатов. Показывает, **как тебя
видят на сайте** и **как ты видишь себя**, позволяет отзеркаливать изображение и
накладывать поверх камеры картинки и гифты — как в OBS, только просто.

## Возможности

- 🪞 **Зеркало** — отдельное управление зеркалом для вывода («как видят меня») и для
  собственного предпросмотра. Если буквы и текст выглядят «наоборот» — переключи одной кнопкой.
- 👁️ **Два предпросмотра** — большая сцена «как видят меня» и маленькое окно «как вижу я».
- 🖼️ **Слои и гифты** — добавляй картинки и эмодзи-гифты, двигай и масштабируй их прямо
  на превью мышкой.
- ⚙️ **Настройки камеры** — выбор устройства, разрешение (до Full HD), режим вписывания.
- ⚡ **Производительность** — отрисовка на canvas через `requestAnimationFrame`, плавные
  анимации интерфейса, лёгкое нативное окно на Tauri.

## Установка (для пользователей)

1. Перейди в раздел [Releases](../../releases).
2. Скачай файл `MirrorCam_*_x64-setup.exe`.
3. Запусти установщик и следуй шагам. Приложение установится как обычная программа Windows.

## Разработка

Требуется [Node.js](https://nodejs.org) 18+ и [Rust](https://www.rust-lang.org/tools/install).

```bash
npm install      # установить зависимости
npm run dev      # запустить в режиме разработки
npm run build    # собрать установщик локально
```

## Релиз

Сборка установщика и публикация происходят автоматически через GitHub Actions при
пуше тега:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Готовый установщик появится в разделе Releases.

## Технологии

- [Tauri 2](https://tauri.app) — нативная оболочка для Windows
- WebRTC `getUserMedia` + Canvas 2D — захват и отрисовка камеры
- Vanilla JS, без тяжёлых фреймворков
